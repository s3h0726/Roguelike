# CHAOS EDEN — 차원 확장 RPG (v2.0)

기존 2D 탑다운 다수 몬스터 전장과 장비·스킬트리·무한 탑·보스·윤회석 환생에 **대형 다중 성장·경제 시스템**을 더한 브라우저 게임입니다. 모든 UI와 재화 명칭은 한국어입니다. 외부 CDN이나 빌드 도구가 없어도 실행됩니다.

## 플레이

- [GitHub Pages](https://s3h0726.github.io/Roguelike/) (저장소의 Pages 설정이 켜져 있을 때)
- `index.html`을 열어 실행. 인접 CSS/JS 파일을 함께 보관해야 합니다.
- 오프라인 단일 HTML `CHAOS_EDEN_DIMENSIONAL_V2.html`도 별도 제공됩니다.

## 초반 빠른 돌파

| 스테이지 | 스테이지당 웨이브 | 한 웨이브당 기본 몬스터 | 비고 |
| --- | ---: | ---: | --- |
| 1~5 | **1** | **3** | 시작 몬스터 체력 대폭 감소, 자동 공격 빠름 |
| 6~10 | **2** | **4** | 빠른 파밍 구간 |
| 11~20 | **3** | 9~11 | 제작·시설·연구 본격화 |
| 21~40 | **5** | 최대 18 | 유물 시너지·각인·탐사 |
| 41+ | **10** | 최대 18 | 고난도 전투·차원 순환 |

`normalStageWave()`는 적 선택용 내부 인덱스 10을 유지하지만 스테이지 완료 판정은 `stageWaveCap()`을 사용합니다. 보스와 특수 전장, 무한 탑은 기존 규칙을 유지합니다.

## 신규 시스템

- **신규 특수 재화 16종**: 철광석, 에테르, 홍염결정, 빙정, 폭풍전하, 공허분진, 시간모래, 별조각, 설계도, 유물파편, 기억결정, 성운합금, 봉인각인, 연금촉매, 심연핵, 우주정수. 기존 6종 재화와 공존합니다.
- **생산 시설 14개**: 원재료 생산부터 중간재 소모형 정제, 최종 자원 제조까지. 자원이 모자라면 자동 가동 정지.
- **연구 기술 20개**: 해금 단계와 선행 관계가 실제 적용되는 연구 트리.
- **유물 18개**: 홍염·공허·시간·별빛·대지·뇌전 6계열(계열별 2개와 3개 획득 시 시너지).
- **특성 18개** 및 **초월 별자리 8개**: 전투·자원·방어·자동화의 영구 성장. 별자리 단계 최대 20.
- **제작법 16개**, **물약 8종**, **탐사 지역 9개**, **의뢰 8종**, **세력 3개**, **시장 거래 12개**, **업적 15개**.
- **자동화 6레벨**: 시설 자동 구매, 선택 제작, 자동 탐사·수령, 의뢰 보상.
- **차원 순환**: 60스테이지부터 재료를 소비해 전투 스테이지만 1부터 재시작하고 영구 공격·생산 배수를 얻는 성장층. 기존 윤회석 환생과 별도입니다.
- **몬스터 접두 효과 5종**: 강철 장갑·초고속·광폭화·취약핵·고대 각성. 15스테이지부터 적용되며 적 능력치와 실제 받는 피해가 바뀝니다.
- **오프라인 생산**: 최대 2시간분의 생산·탐사 시간이 저장됩니다.

## 게임 조작

WASD/방향키 이동 · Shift 대시 · 1~3 스킬 · R 카오스 대폭발. 모바일은 조이스틱과 버튼을 사용합니다. 생산·연구 등 장기 성장 메뉴는 오른쪽(모바일은 전장 아래) `차원 확장 연구소`에서 선택합니다.

## 개발 파일

- `game.js`: 기존 RPG의 보스·전장·장비·스킬·환생 처리, 빠른 스테이지 웨이브 상한 적용
- `horde.js`: 다수 몬스터와 접두 효과 반영, 초반 공격 간격 및 다수 몬스터 생성
- `battlefield.js` / `battlefield.css`: 화려한 Canvas2D 탑다운 이펙트와 조작
- `advanced-core.js`: 경제·연구·유물·제작·탐사·계약·자동화·별자리 순수 로직
- `advanced-ui.js` / `advanced.css`: 차원 확장 연구소와 현재 진행·재화 패널
- `tests/*.test.mjs`: 회귀 검사

## 검증

```bash
npm test
npm run check
```

Node.js 자동 테스트 18개, 브라우저 PC·모바일 인라인 스크립트 실행 검증, 기존 1~10스테이지 빠른 진행 검증 완료. 로컬 테스트 환경의 직접 URL 네비게이션은 차단되어 DOM 콘텐츠를 주입한 Chromium 검증을 진행했습니다. GitHub Pages 배포 상태는 별도로 확인해야 합니다.

## 저장 데이터

기존 `artifactCoreRpgFullRemake` 저장 데이터 안에 `state.advanced`를 추가하는 방식으로 구성했습니다. 예전 저장 파일에 고급 시스템 데이터가 없으면 새 기본 상태를 추가합니다. 기존 무기·스킬·윤회석 환생 정보는 유지합니다. 차원 순환 시 영구 경제·연구·유물·별자리 성장도 유지됩니다.
